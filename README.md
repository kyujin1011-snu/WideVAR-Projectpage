# WideVAR Project Page

This directory contains a static project page for:

**WideVAR: Coherent Wide Image and Video Generation in Visual Autoregressive Models**

The current project page includes the method overview, qualitative examples, wide-image Table 1
values, qualitative comparison panel, an arXiv paper entry, and a BibTeX section. Project-page figures are rebuilt from the
high-resolution source assets in `assets/original` where native image assets are available.

## Files

- `index.html`: static project page
- `styles.css`: page styling
- `WideVAR__Coherent_Wide_Image_and_Video_Generation_in_Visual_Autoregressive_Models.pdf`: local paper copy, not linked from the page while the arXiv URL is unavailable
- `assets/figures/*.png`: project-page image assets generated from native sources where possible
- `assets/original/fig/*.png`: high-resolution source figures
- `assets/original/sections/*.tex`: TeX section sources used for page text and reference material
- `assets/original/neurips_2026.tex`: main TeX source
- `assets/*.png`: full-page reference assets

## Maintenance

- Enable the arXiv paper entry in `index.html` when the official URL is available.
- Fill the BibTeX code block in `index.html` when the citation is finalized.
- Update links when official code, videos, or project URLs are available.
- Refresh project-page figures from `assets/original/fig` when source media changes.
